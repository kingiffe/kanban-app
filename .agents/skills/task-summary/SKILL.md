# 任務進度與待辦摘要 (Task Summary)

本技能用於彙整待辦事項的整體進度與未完成項目。當使用者詢問進度狀況、未完成任務時，依照狀態分組、優先度排序，並計算完成率反饋給使用者。

---

## 1. 觸發時機

當使用者提出以下或類似意圖之問題時啟用：
- 「還有哪些事沒做完？」
- 「目前進度如何？」
- 「幫我整理未完成的任務」
- 「目前待辦清單的完成率是多少？」

---

## 2. 資料規格與約定

嚴格遵循專案規定 [.agents/rules/todo-data.md](../../rules/todo-data.md) 的欄位與值域約定：
- **欄位**：標題（必填、50 字內）、優先度、分類、狀態、負責人。
- **優先度值域**：`High`、`Medium`、`Low`。
- **分類值域**：`工作`、`生活`。
- **狀態值域**：`Todo`（待處理）、`Process`（進行中）、`Done`（已完成）。

> 未經使用者明確同意，不得新增其他欄位或選項。

---

## 3. 計算與排序規則

### 完成率計算
- **總任務數** = `Todo 數量` + `Process 數量` + `Done 數量`
- **完成率** = `(Done 數量 / 總任務數) * 100%`（四捨五入至小數點後第一位，若總任務數為 0 則顯示 0%）

### 排序原則
- **狀態分組順序**：
  1. `Process`（進行中，需優先跟進關注）
  2. `Todo`（待處理，後續待辦）
  3. `Done`（已完成，歷史成果）
- **組內優先度排序**：
  - 各組內依據優先度權重排序：`High` > `Medium` > `Low`。
  - 同優先度項目保持既有順序。

---

## 4. 回應格式範本

回覆使用者時，採用清晰、專業的 Markdown 排版，結構如下：

### 步驟一：進度數據總覽
以簡要摘要列出目前進度：
- **整體完成率**：`XX.X%` (Done / Total)
- **總任務數**：共 N 筆
- **各狀態分佈**：
  - 進行中 (`Process`)：X 筆
  - 待處理 (`Todo`)：Y 筆
  - 已完成 (`Done`)：Z 筆

### 步驟二：未完成任務清單（Process 與 Todo）
優先呈現尚未完成的事項，使用表格呈現：

| 狀態 | 優先度 | 分類 | 標題 | 負責人 |
| :--- | :--- | :--- | :--- | :--- |
| Process | High | 工作 | ... | ... |
| Process | Medium | 生活 | ... | ... |
| Todo | High | 工作 | ... | ... |
| Todo | Low | 生活 | ... | ... |

*(若無進行中或待處理任務，應明確標記「目前沒有進行中/待處理的任務」)*

### 步驟三：已完成任務清單 (Done)
列出已完成事項（可使用列表或折疊/表格顯示），確認歷史成果。

### 步驟四：行動建議與重點提醒
- 若有 `High` 優先度且處於 `Process` 或 `Todo` 狀態的項目，於文末特別標記提醒使用者優先推進。
